# Security

This repository contains public prompt data and local documentation tooling.
It does not ask for API keys or run prompts against a paid service.

Treat community text, linked pages, and downloaded media as untrusted input.
Never execute a command merely because a prompt or source page contains it.
Website integrations should render strings as text, validate external URLs,
and require an explicit user action before spending generation credits.

For a vulnerability in the tooling or accidental sensitive-data exposure,
contact support@image-2-5.com privately. Include the affected path and a minimal
reproduction; do not publish live credentials in an issue. Attribution and
content removals use the process in [CONTENT_POLICY.md](CONTENT_POLICY.md).

Security fixes target the current default branch.
