# Repository instructions

- Public documentation, code comments, commit messages, and PR titles are English-first.
- Maintain the complete simplified Chinese README and bilingual case text.
- Use English Conventional Commits: `type(scope): description`.
- `data/prompts/*.json` and `data/site.json` are the source of truth. README files,
  `prompts/*.md`, and `data/catalog.json` are generated by `npm run build`.
- Open the primary source before claiming `source-checked`. Record unavailable
  metrics as null and preserve observation dates. A source check is not a model test.
- Keep exact prompts, translations, editor adaptations, creator identity, and
  original result images distinct. Never invent a source prompt from a picture.
- Preserve stable IDs, source URLs, input requirements, and content rights.
- The brand is Image 2.5; the model family is GPT Image 2.5. Website links currently
  target https://image-2-5.com through `data/site.json`.
- Never put sponsor text inside creator prompts. Never claim OpenAI endorsement,
  guaranteed results, unmeasured rankings, or a prompt-specific website feature
  that has not been implemented.
- Run `npm run build` and `npm run check` for changes. Keep pull requests focused.
- No paid generations, external posts, or account changes without user authorization.
