# Image 2.5 brand assets

Official project brand: **Image 2.5**, at https://image-2-5.com.
The model name remains **GPT Image 2.5**.

The logo and open-frame mark are reused from the owner's Image 2.5 brand system,
with authorization for this repository. The wordmark uses outlined Space Grotesk;
its SIL Open Font License is included. The banner is original SVG layout for
this collection, using warm canvas `#F5F4EF`, ink `#202824`, and cobalt `#3456CE`.

These assets identify the project. They are not model-generated examples and
do not imply affiliation with OpenAI. The tooling license does not grant
trademark rights. Forks should replace branding that could imply endorsement.
